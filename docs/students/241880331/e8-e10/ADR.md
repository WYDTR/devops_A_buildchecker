# 决策记录

## 背景与约束

在课程受限 C/Make 配置上验证历史依赖图复用和发现变化。
正确性优先，性能使用本机真实扫描计时。

## 选择与替代方案

沿用参考实现的全局保守失效策略：
预处理指令、文件集合、配方、支持的编译选项
或编译器身份变化时，刷新两个对象目标；
签名相同时复用实际图。

每次仍重新读取当前声明，
重新计算 findings、added、resolved，
避免只复用旧发现而漏掉声明修复。

替代方案是仅刷新受影响目标。
它可能减少工作量，
但需要可靠的影响传播和失效规则；
本次没有实现该优化。

## 代价与覆盖范围

保守刷新可能对未受影响的 helper.o 做额外依赖采集。
小样例刷新路径可能略慢于全量，
报告保留真实计时。

支持范围限定于参考实现接受的显式规则、
简单变量和编译配置。

另测宏配置激活依赖场景五次，
并执行真实动态重检。
